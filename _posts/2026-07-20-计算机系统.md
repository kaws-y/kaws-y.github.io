## 2. 核心知识

### 2.1 数据表示

- **机器数与码制**：正数原码=反码=补码；负数反码为原码数值位取反，补码为反码 +1。补码使减法可用加法实现，0 只有一种表示。n 位补码范围：\\(-2^{n-1}\\) ~ \\(+2^{n-1}-1\\)。
- **溢出判断**：同号相加才可能溢出；结果的符号与操作数符号不同即溢出（或用双符号位 01/10 判断）。
- **浮点数**：\\(N = M \times 2^E\\)，阶码 E 决定范围，尾数 M 决定精度；对阶（小阶向大阶看齐）→ 尾数运算 → 规格化 → 舍入 → 溢出判断。IEEE 754 单精度 32 位（1 符号 + 8 阶码 + 23 尾数）、双精度 64 位。

### 2.2 存储层次

层次（快→慢、小→大）：寄存器 → Cache → 主存 → 辅存（磁盘/SSD）。依据是**程序局部性原理**（时间局部性 + 空间局部性）。

- **Cache 命中率**：\\(H = N_c/(N_c+N_m)\\)；平均访问时间 \\(T_a = H \times T_c + (1-H) \times T_m\\)。
- **主存-Cache 映射**：
  - 直接映射：每主存块只能放一个 Cache 行，实现简单、冲突率高。
  - 全相联映射：任意放，冲突最低、硬件成本高。
  - 组相联映射：折中（如 2 路组相联）。
- **替换算法**：LRU、FIFO、随机。
- **写策略**：写回法（写命中只改 Cache，换出时写回主存）、写直达法（同时写 Cache 与主存）。
- **虚拟存储器**：页式/段式/段页式，地址由 MMU 转换；TLB 快表加速。

### 2.3 磁盘与 RAID

| RAID 级别 | 机制 | 特点 |
| --- | --- | --- |
| RAID 0 | 条带化，无冗余 | 读写快，无容错，一块坏全丢 |
| RAID 1 | 镜像 | 读快、写较慢，利用率 50% |
| RAID 3/4 | 专用校验盘 + 条带 | 读快，校验盘瓶颈 |
| RAID 5 | 分布式奇偶校验（至少 3 盘） | 读快、写有校验开销，坏 1 盘可恢复，利用率 (N-1)/N |
| RAID 6 | 双分布式校验（至少 4 盘） | 可坏 2 盘，利用率 (N-2)/N |
| RAID 10 | 镜像 + 条带 | 性能与可靠性兼得，成本高（利用率 50%） |

### 2.4 指令系统与流水线

- **寻址方式**：立即、直接、间接、寄存器、寄存器间接、基址、变址、相对寻址。有效地址计算是选择题常客。
- **CISC vs RISC**：CISC 指令多而复杂、变长、微程序控制；RISC 指令少而简单、定长、硬布线控制 + 流水线和大量寄存器。
- **流水线**：把指令执行分为取指 IF、译码 ID、执行 EX、访存 MEM、写回 WB 等阶段并行。
  - 吞吐率 \\(TP = n / T_k\\)（n 条指令，k 段流水，总时间 \\(T_k = (k + n - 1)\Delta t\\)）。
  - 加速比 \\(S_p = T_{非流水} / T_{流水}\\)。
  - **相关冲突**：结构相关（资源冲突）、数据相关（RAW/WAR/WAW）、控制相关（转移）；解决：转发（旁路）、暂停、分支预测。

### 2.5 性能评价

- **Amdahl 定律**：系统加速比 \\(S = 1 / [(1-F) + F/S_F]\\)，F 是可改进部分比例，\\(S_F\\) 是该部分加速比。**含义**：加速某部分收益受其占比限制（经典：若某功能占 10%，即使无限加速，整体也只提升约 11%）。
- **CPI**（每条指令周期数）、**MIPS** = 时钟频率 / CPI（单位 MHz → 百万条指令/秒）。
- 基准测试程序（SPEC 等）用于综合评价。

## 3. 易混淆概念对比

| 对比项 | 关键区别 |
| --- | --- |
| 原码 vs 补码 | 补码统一了 +0/-0，减法可用加法实现，表示范围多一个负数 |
| Cache 直接映射 vs 全相联 | 直接映射冲突率高但硬件简单；全相联相反 |
| 写回 vs 写直达 | 写回延迟写主存、速度快但有一致性风险；写直达一致性好但写慢 |
| RAID 5 vs RAID 6 | RAID5 容 1 盘故障；RAID6 容 2 盘故障 |
| RISC vs CISC | RISC 指令精简、定长、流水线友好；CISC 指令丰富、变长 |
| Amdahl 定律 vs Gustafson 定律 | Amdahl 固定问题规模；Gustafson 认为规模随处理器数增长 |

## 4. 考试重点

1. Cache 命中率与平均访问时间计算；主存地址到 Cache 行的映射计算。
2. 补码范围、溢出判断、浮点数对阶与规格化。
3. RAID 级别选择（性能 vs 可靠性 vs 磁盘利用率）。
4. 流水线时空图、吞吐率、加速比计算。
5. Amdahl 定律计算（给出可加速比例与加速倍数求整体加速比）。

## 5. 典型例题（原创模拟题）

**例题 1**：某程序可并行部分占 80%，若将这部分加速 4 倍，整体加速比约为（　）。
A. 1.6　B. 2.0　C. 2.5　D. 3.2

**答案**：C。**解析**：按 Amdahl 定律 \\(S = 1/[(1-0.8) + 0.8/4] = 1/(0.2+0.2) = 2.5\\)。

**例题 2**：Cache 命中率 95%，Cache 访问时间 1ns，主存访问时间 20ns，平均访问时间约为（　）。
A. 1.95ns　B. 2.0ns　C. 2.5ns　D. 19ns

**答案**：B。**解析**：\\(T_a = 0.95\times1 + 0.05\times20 = 0.95 + 1 = 1.95\\) ns，约 2.0ns。

## 6. 记忆技巧

- 存储层次：**寄 Cache 主辅**，越往上越快越小越贵。
- RAID 口诀：**0 条带无冗余，1 镜像，5 分布校验坏一盘，6 双校验坏两盘，10 镜条兼顾**。
- Amdahl：**整体收益 = 1 /（不可加速部分 + 可加速部分/加速倍数）**。

## 7. 芝士架构资料补充

> 来源：《公共知识红宝书》第 9 章。本章整体次重点★★★☆☆，其中流水线技术为重点★★★★★。

### 7.1 数据表示与编码（★★★☆☆）
- 机器数：原码、反码、补码、移码。正数三码相同；负数补码 = 反码 + 1。
- n 位补码范围：\\(-2^{n-1} \sim +(2^{n-1}-1)\\)；0 的补码唯一。
- 浮点数 \\(N = M \times 2^E\\)：阶码 E 决定表示范围，尾数 M 决定精度；运算需对阶（小阶向大阶看齐）→ 尾数运算 → 规格化 → 舍入 → 溢出判断。

### 7.2 存储器系统（★★★☆☆）
- 层次：寄存器 → Cache → 主存 → 外存；依据程序局部性原理。
- Cache 命中率 \\(H = N_c/(N_c+N_m)\\)；平均访问时间 \\(T_a = H \cdot T_c + (1-H) \cdot T_m\\)。
- 地址映射：直接映射、全相联映射、组相联映射；替换算法 LRU/FIFO/随机。
- 虚拟存储器：页式、段式、段页式，由 MMU 完成地址转换，快表（TLB）加速。

### 7.3 寻址方式（★★★☆☆）
立即寻址、直接寻址、间接寻址、寄存器寻址、寄存器间接寻址、基址寻址、变址寻址、相对寻址。有效地址（EA）计算是选择题常客。

### 7.4 流水线技术（★★★★★）
- 把指令处理分为取指 IF、译码 ID、执行 EX、访存 MEM、写回 WB 等阶段并行。
- **时空图**：横轴时间、纵轴功能段；n 条指令、k 段流水，总时间 \\(T_k = (k + n - 1)\Delta t\\)。
- **吞吐率** \\(TP = n / T_k\\)；**加速比** \\(S_p = T_{串行} / T_{流水}\\)；**效率** = 时空图中阴影面积 / 总面积。
- 相关冲突：结构相关（资源冲突）、数据相关（RAW/WAR/WAW）、控制相关（转移）；解决办法：资源重复、转发（旁路）、暂停、分支预测。

### 7.5 Amdahl 定律与性能评估（★★★☆☆）
- **Amdahl 定律**：\\(S = 1 / [(1-F) + F/S_F]\\)，F 为可改进部分比例，\\(S_F\\) 为其加速比。含义：整体加速受可改进部分占比限制。
- 性能指标：MIPS（每秒百万条指令）、MFLOPS、CPI（每条指令时钟周期数）。
- 基准测试程序：SPEC 等用于综合性能评价。
