# 06 大模型应用（RAG / MCP / Agent）

> 来源：《案例冲刺宝典》第 16 章。重点★★★★★，近年新增热点。

## 1. RAG 检索增强生成（★★★★★）

> 解决问题：模型怎么拿到企业自己的知识（知识时效性、私有数据、减少幻觉）。

**完整流程**：
1. **数据准备**：收集企业文档（PDF、Word、网页等），清洗、去重。
2. **分块策略（Chunking）**：按语义/固定长度切分，设置重叠窗口；块大小影响检索精度与上下文完整性。
3. **向量化 Embedding**：用嵌入模型把文本块转为高维向量，保留语义信息。
4. **索引存储**：向量存入向量数据库（如 Milvus、Pinecone），建立 ANN 近似最近邻索引。
5. **检索增强**：用户问题向量化 → 在向量库检索相似块（Top-K）→ 与问题拼成增强 Prompt。
6. **生成答案**：大模型基于检索到的上下文生成答案，并附带来源引用。

- 优点：无需微调即可注入新知识、可溯源、降低幻觉。
- 挑战：分块质量、检索召回率、上下文长度限制、向量库选型。

## 2. MCP 模型上下文协议（★★★★★）

> **解决什么问题**：大模型与外部工具/数据源之间的接口标准不统一，每接一个工具都要单独适配。MCP 提供**统一协议**，让模型以标准方式发现并调用外部能力与数据。

- 类比：像"AI 应用的 USB-C 接口"，标准化连接。
- **MCP 工具组成**：
  - **Tools（工具）**：可被模型调用的函数/操作（如查询数据库、发邮件）。
  - **Resources（资源）**：可读取的数据源（文件、数据库记录）。
  - **Prompts（提示模板）**：预定义的提示词模板。
- 架构：MCP Host（AI 应用）→ MCP Client（协议客户端）→ MCP Server（暴露能力的服务）。

## 3. 智能体 Agent（★★★☆☆）

- **简介**：能感知环境、自主决策、调用工具完成任务的系统；以大模型为"大脑"。
- **架构**：大模型（推理规划）+ 工具集（执行）+ 记忆（短期上下文/长期存储）+ 感知与行动接口。
- **ReAct 模式**：Reasoning + Acting 交替——先推理（Thought）→ 调用工具（Action）→ 观察结果（Observation）→ 再推理，循环直到完成任务。
- **规划-执行模式（Plan-and-Execute）**：先由规划器拆解任务为子任务序列，再由执行器逐一执行，适合复杂长流程任务。
- **Skill（★★★★★）**：封装可复用的领域能力/操作流程供智能体调用，是智能体能力扩展的关键单元。

## 4. 案例答题要点
给出企业智能客服/知识助手场景，要求设计架构。答题主线：知识如何入库（RAG 数据准备→分块→向量化→索引）→ 用户提问如何检索增强 → 如何调用外部系统（MCP/Agent + 工具）→ 如何保证准确性与可溯源。结合安全性（权限控制、敏感信息过滤）展开。
