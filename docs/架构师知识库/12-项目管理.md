## 2. 核心知识

### 2.1 框架

- **五大过程组**：启动 → 规划 → 执行 → 监控 → 收尾。
- **十大知识领域**（PMBOK）：整合、范围、进度、成本、质量、资源、沟通、风险、采购、相关方。
- **项目章程**：由项目发起人签发，正式授权项目存在并赋予项目经理权力。

### 2.2 范围管理

- **WBS（工作分解结构）**：面向可交付成果的层次分解，是范围基线核心（范围基线 = 项目范围说明书 + WBS + WBS 词典）。
- **范围蔓延**：未经变更控制的范围扩大；需通过变更请求与 CCB 控制。

### 2.3 进度管理（计算必考）

- **网络图（AOA/AON）**：活动-on-箭线 / 活动-on-节点；虚活动表示依赖关系（不消耗时间与资源）。
- **关键路径法（CPM）**：网络中**最长路径**决定项目最短工期；关键路径上活动总时差为 0。
  - **总时差 TF** = 最迟开始 LS - 最早开始 ES（不影响总工期的可延迟量）。
  - **自由时差 FF** = 紧后活动最早开始 - 本活动最早完成（不影响紧后活动的最早开始）。
- **PERT（计划评审技术）**：三点估算 \(t_e = (t_o + 4t_m + t_p)/6\)，标准差 \(\sigma = (t_p - t_o)/6\)，方差可加。
- **甘特图**：横道图，直观展示时间安排但不显示逻辑关系。
- **进度压缩**：赶工（加资源，增成本）vs 快速跟进（并行活动，增风险）。

### 2.4 成本管理：挣值管理 EVM（必考公式）

三个基本参数：
- **PV（计划价值）**：计划完成工作的预算成本（BCWS）。
- **EV（挣值）**：实际完成工作的预算成本（BCWP）。
- **AC（实际成本）**：实际完成工作的实际成本（ACWP）。

四个评价指标：

| 指标 | 公式 | 判读 |
| --- | --- | --- |
| 进度偏差 SV | \(SV = EV - PV\) | SV>0 进度提前 |
| 成本偏差 CV | \(CV = EV - AC\) | CV>0 成本节约 |
| 进度绩效指数 SPI | \(SPI = EV / PV\) | >1 提前 |
| 成本绩效指数 CPI | \(CPI = EV / AC\) | >1 节约 |

**完工估算**：典型偏差（按当前绩效）\(EAC = BAC / CPI\)；非典型偏差 \(EAC = AC + (BAC - EV)\)。其中 BAC 为完工预算。

### 2.5 项目估算

- **功能点法**：按外部输入、外部输出、查询、内部逻辑文件、外部接口文件五类计数，乘以复杂度权重得未调整功能点，再乘调整因子。与语言无关。
- **COCOMO**：构造性成本模型，基本型/中间型/详细型；工作量 \(E = a \times (KLOC)^b \times EAF\)。
- **其他**：类比估算、参数估算、自下而上估算、德尔菲技术（匿名多轮专家意见）。

### 2.6 风险管理

- 流程：风险识别 → 定性分析（概率×影响矩阵、排序）→ 定量分析（蒙特卡洛、决策树、EMV 预期货币价值）→ 风险应对 → 风险监控。
- **消极风险（威胁）应对**：规避、转移、减轻、接受。
- **积极风险（机会）应对**：开拓、提高、分享、接受。
- **风险登记册**是核心输出，持续更新。

## 3. 易混淆概念对比

| 对比项 | 关键区别 |
| --- | --- |
| 总时差 vs 自由时差 | 总时差相对项目总工期；自由时差相对紧后活动最早开始 |
| 赶工 vs 快速跟进 | 赶工加资源增成本；快速跟进并行活动增风险与返工 |
| SV/CV 与 SPI/CPI | 偏差是绝对量（EV-PV/EV-AC）；指数是相对量（除法） |
| 功能点 vs 代码行 | 功能点按用户可见功能计量、与语言无关；LOC 依赖具体实现语言 |
| 风险转移 vs 风险减轻 | 转移把影响与责任交给第三方（保险/外包）；减轻降低发生概率或影响 |
| 项目章程 vs 项目范围说明书 | 章程授权项目（发起人签发）；范围说明书定义工作边界 |

## 4. 考试重点

1. 网络图求关键路径、工期、总时差（先正推最早、再逆推最迟）。
2. 挣值计算：给 PV/EV/AC 求 SV/CV/SPI/CPI/EAC。
3. PERT 三点估算与标准差。
4. 风险应对策略归类（买保险 = 转移；增加测试 = 减轻；改变方案绕开风险 = 规避）。
5. WBS 的编制原则（100% 规则、面向可交付成果）。

## 5. 典型例题（原创模拟题）

**例题 1**：某项目 BAC=100 万元，检查时 PV=40 万，EV=30 万，AC=35 万。下列判断正确的是（　）。
A. 进度提前、成本节约　B. 进度落后、成本超支
C. 进度提前、成本超支　D. 进度落后、成本节约

**答案**：B。**解析**：\(SV = EV-PV = 30-40 = -10 < 0\)，进度落后；\(CV = EV-AC = 30-35 = -5 < 0\)，成本超支。若按当前绩效，\(EAC = BAC/CPI = 100/(30/35) \approx 116.7\) 万元。

**例题 2**：某活动乐观时间 4 天、最可能 7 天、悲观时间 16 天，其 PERT 期望工期为（　）。
A. 7 天　B. 8 天　C. 9 天　D. 10 天

**答案**：B。**解析**：\(t_e = (4 + 4\times7 + 16)/6 = 48/6 = 8\) 天。

## 6. 记忆技巧

- 挣值口诀：**PV 计划、EV 干完、AC 花钱；SV=EV-PV，CV=EV-AC；大于零是好事**。
- 关键路径：**最长路决定最短工期，路上时差为零**。
- 风险应对：**威胁——避转减受；机会——开提分享受**。
- 十大领域口诀（节选）：**整范进成质，资沟风险采相关方**。

## 7. 随堂测试

1. SPI=0.8 表示什么？
2. 关键路径上的活动总时差通常是多少？
3. 购买保险属于哪种风险应对策略？

<details>
<summary>参考答案</summary>

1. 进度绩效指数 0.8 < 1，表示实际进度落后于计划（仅完成计划工作量的 80%）。
2. 0（在不考虑外部约束的情况下）。
3. 风险转移。
</details>

## 8. 芝士架构资料补充

> 来源：《公共知识红宝书》第 8 章。

### 8.1 本章考点分布（★★★☆☆）
红宝书将项目管理整体列为次重点，其中**进度管理为重点★★★★★**，范围、成本、配置、风险管理为次重点。配置管理在红宝书中归入本章（本知识库第 1 章亦有涉及，两处呼应）。

### 8.2 配置管理补充（★★★☆☆）
- 配置管理核心活动：制定配置管理计划、配置项识别、工作空间管理、版本管理、变更控制、配置状态报告、配置审计、发布管理。
- **配置项**：需求文档、设计文档、源代码、测试用例、工具、数据等纳入管理的实体。
- **基线**：经正式评审后冻结的配置项集合；基线变更须经 CCB（变更控制委员会）审批。
- 配置审计验证配置项的完整性与一致性；配置状态报告记录配置项状态与变更历史。

### 8.3 风险管理补充（★★★☆☆）
- 风险 = 不确定的事件或条件，一旦发生会对项目目标产生正面或负面影响。
- 流程：风险识别 → 风险定性分析（概率 × 影响矩阵）→ 风险定量分析 → 风险应对计划 → 风险监控。
- 应对：威胁（规避、转移、减轻、接受）；机会（开拓、提高、分享、接受）。
- 风险登记册是贯穿全程的核心文档。
